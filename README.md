El tope real de cada producto es el menor entre 3 y su stock disponible.Ciclo de vida del carrito: No se conserva al cerrar sesión; se vacía al cerrar e iniciar sesión.Control de stock: Agregar al carrito no descuenta stock, solo lo valida. El descuento efectivo corresponde a la confirmación del pedido (fuera de esta entrega).Seguridad: El identificador del cliente se obtiene siempre de la sesión autenticada (nunca de lo enviado por el navegador), previniendo que un usuario modifique el carrito de otro.Fuera de alcance: Pagos, confirmación de pedido, panel de administración, historial de pedidos y filtros por categoría.📦 Paquetes NuGetUsaditos2026.BDMicrosoft.EntityFrameworkCore.SqlServer — Proveedor de SQL Server para EF Core.Microsoft.EntityFrameworkCore.Tools — Herramientas para migraciones (add-migration, update-database).Usaditos2026.ServiciosMicrosoft.Extensions.Identity.Core — PasswordHasher para guardar contraseñas hasheadas.Usaditos2026.Server.ClientMicrosoft.AspNetCore.Components.Authorization — AuthorizeView para mostrar contenido según la sesión.Usaditos2026.ServerMicrosoft.EntityFrameworkCore.SqlServer — Registro del contexto de base de datos.Microsoft.EntityFrameworkCore.Tools — Herramientas de EF Core.Swashbuckle.AspNetCore — Swagger para documentación y pruebas de la API.⚙️ Configuración de la Cadena de ConexiónEdita el archivo appsettings.json ubicado en Usaditos2026.Server:{
